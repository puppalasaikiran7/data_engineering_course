window functions 
_________________

window functions in sql are powerfull set of functions that allow us to perform calculations on set of row , these calculations can be performed 
with any collapsing of rows that is with out grouping rows 

syntax :
________

select col1 , windows_functions(col2) over([ partition by column_name1 ] [ order by column_name3])as new_column from table_name;



functions:
__________

aggregate function ( count , sum , avg , min , max  ) 
rank function ( row_number , rank , dense_rank ,  ntile , lead , lag ) 




rank() - rank function assign rank to row within partition , with the same rank given to rows with same identical values , if the two rows share 	the same rank the next rank is skipped 

example: select name , department , salary , rank() over( partition  by department  order by salary desc ) as emp_rank from employee;
________


dense_rank() - denserank function assigns ranks to row within partition , with the same rank given to rows with same identical values , if the 			two rows share the same rank the next rank is not skipped 

example: select name , department , salary , dense_rank() over( partition by department order by salary desc ) as emp_dense_rank from employee;
_______


row_number() - this will assign the unique number to each row 

example : select name , department , salary , row_number() over (partition by department order by salary desc ) as emp_row from employee;
_______


lead () - this will look a head for the next row values , gets the next row values

example : select name , department , salary , lead(salary) over ( partition by department order by salary desc ) as next_salary from employee;

lag() - it does the opposite of lead , gets the previous row values

example : select name , department , salary , lag(salary) over ( partition by department order by salary desc ) as previous_salary from employee;
